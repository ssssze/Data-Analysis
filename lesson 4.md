
# Lesson 4: Data Cleaning

## What is Data Cleaning?

Data cleaning is the process of identifying and correcting errors, missing information and inconsistencies in a dataset. It helps make data accurate, reliable and ready for analysis.

## 1. Handling Missing Values
Identifying empty or missing information in a dataset and deciding how to manage it.

## 2. Removing Duplicates
Finding and removing repeated records to avoid inaccurate results.

## 3. Correcting Data
Fixing spelling mistakes, incorrect values and inconsistent formats.

## 4. Handling Outliers
Identifying unusually high or low values that may affect the analysis.

## 5. Checking Data Types
Ensuring that information is stored in the correct format, such as numbers, dates or text.

## 6. Checking Data Quality
Reviewing the dataset to ensure that the information is accurate, consistent and complete.

## Learning Goal
Learn how to clean and prepare datasets so they can be used for accurate and reliable data analysis.
