
# Lesson 3: Data Cleaning, Manipulation, EDA and Data Visualization

## 1. Data Cleaning

Data cleaning is the process of identifying, correcting and removing errors or inconsistencies in a dataset. It helps ensure that the information is accurate, complete and reliable before analysis.

### 1.1 Handling Missing Values
- Identifying empty or missing information.
- Understanding why values may be missing.
- Removing or replacing missing values.
- Choosing suitable methods to handle incomplete data.

### 1.2 Removing Duplicates
- Identifying repeated rows and records.
- Understanding how duplicates affect analysis.
- Removing unnecessary duplicate entries.

### 1.3 Correcting Data
- Fixing spelling mistakes and incorrect information.
- Correcting inconsistent formats.
- Standardising text and category names.
- Converting values into appropriate formats.

### 1.4 Handling Outliers
- Understanding what outliers are.
- Identifying unusually high or low values.
- Using statistical methods to detect unusual values.
- Deciding whether unusual values should be investigated, corrected or retained.

### 1.5 Checking Data Types
- Understanding numerical, text, date and category data types.
- Identifying incorrect data types.
- Converting columns into suitable data types.

## 2. Data Manipulation

Data manipulation is the process of changing, organising and transforming data into a suitable format for analysis. It helps make datasets easier to work with and understand.

### 2.1 Selecting and Filtering Data
- Selecting specific rows and columns.
- Filtering information using conditions.
- Extracting relevant records from a dataset.

### 2.2 Sorting Data
- Arranging information in ascending and descending order.
- Sorting data based on one or multiple columns.
- Organising records for easier comparison.

### 2.3 Adding and Removing Data
- Adding new columns and rows.
- Removing unnecessary columns and records.
- Renaming columns.
- Modifying existing values.

### 2.4 Grouping and Aggregating Data
- Grouping information based on categories.
- Calculating totals, averages and counts.
- Summarising information within different groups.

### 2.5 Combining Datasets
- Understanding how datasets can be combined.
- Merging datasets using common columns.
- Concatenating datasets by joining rows or columns.
- Understanding different types of joins.

### 2.6 Reshaping Data
- Changing the structure of a dataset.

- Pivoting and melting data.

## 3. Exploratory Data Analysis (EDA)

Exploratory Data Analysis (EDA) is the process of examining and understanding a dataset before performing detailed analysis. It helps discover patterns, trends, relationships and unusual information.

### 3.1 Understanding Dataset Structure
- Checking the number of rows and columns.
- Examining column names and data types.
- Understanding the overall structure of a dataset.
- Identifying the type of information available.

### 3.2 Descriptive Statistics
- Understanding mean, median and mode.
- Calculating minimum and maximum values.
- Understanding range, variance and standard deviation.
- Using statistical summaries to understand numerical data.

### 3.3 Understanding Data Distributions
- Examining how values are spread across a dataset.
- Identifying common and uncommon values.
- Understanding symmetrical and skewed distributions.
- Recognising patterns in numerical data.

### 3.4 Identifying Relationships
- Examining relationships between different variables.
- Understanding positive and negative correlations.
- Using correlation to measure relationships.
- Understanding that correlation does not necessarily mean causation.

### 3.5 Detecting Patterns and Anomalies
- Identifying unusual values and observations.
- Discovering repeated patterns.
- Recognising increasing and decreasing trends.
- Investigating unexpected results.

## 4. Data Visualization

Data visualization is the process of presenting information through charts, graphs and other visual formats. It makes complex information easier to understand, compare and interpret.

### 4.1 Introduction to Data Visualization
- Understanding the importance of visualizing data.
- Learning how graphs help communicate information.
- Choosing suitable charts based on the type of data.
- Understanding how to present information clearly.

### 4.2 Types of Charts and Graphs
- **Bar Chart:** Used to compare values between different categories.
- **Line Graph:** Used to show changes and trends over time.
- **Pie Chart:** Used to display proportions of a whole.
- **Histogram:** Used to show the distribution of numerical data.
- **Scatter Plot:** Used to examine relationships between two numerical variables.
- **Box Plot:** Used to display data distributions, spread and potential outliers.

### 4.3 Creating Visualizations
- Introduction to Matplotlib and Seaborn.
- Creating different types of charts and graphs.
- Customising chart titles, labels and axes.
- Changing colours, sizes and chart styles.
- Displaying multiple visualizations.

### 4.4 Interpreting Visualizations
- Identifying patterns and trends in graphs.
- Comparing different categories.
- Understanding distributions and relationships.
- Recognising unusual values through visual representations.
- Drawing conclusions from visual information.

### 4.5 Communicating Findings
- Choosing appropriate visualizations.
- Presenting information clearly and accurately.
- Avoiding misleading graphs.
- Using charts to support analysis and conclusions.

---

## Learning Goal

Develop the ability to clean and transform datasets, explore information, identify patterns and relationships, create meaningful visualizations and communicate findings clearly.
