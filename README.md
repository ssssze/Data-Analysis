# Data-Analysis

## About
This repository documents my journey of learning Data Analysis using Python. It covers essential concepts, practical coding exercises, and techniques for working with real-world datasets.

## Learning Topics

### 01. Python Basics
- Variables, data types and operators
- Lists, dictionaries and tuples
- Loops and conditional statements
- Functions and file handling

### 02. NumPy
- Arrays and array operations
- Indexing and slicing
- Mathematical and statistical functions

### 03. Pandas
- Series and DataFrames
- Reading CSV and Excel files
- Selecting, filtering and sorting data
- Working with columns and rows

### 04. Data Cleaning
- Handling missing values
- Removing duplicates
- Correcting data types
- Handling inconsistent and incorrect data
- Detecting outliers

### 05. Data Manipulation
- Filtering and grouping data
- Sorting and aggregation
- Merging and joining datasets
- Pivot tables and reshaping data

### 06. Exploratory Data Analysis (EDA)
- Understanding datasets
- Descriptive statistics
- Finding patterns and trends
- Correlation and outlier analysis

### 07. Data Visualization
- Matplotlib and Seaborn
- Bar charts, line graphs and histograms
- Scatter plots and heatmaps
- Creating meaningful visualizations

### 08. Statistics
- Mean, median and mode
- Variance and standard deviation
- Probability and distributions
- Correlation and hypothesis testing

### 09. Real-World Datasets
- Finding and importing datasets
- Cleaning and analyzing real data
- Creating visualizations
- Interpreting results and presenting findings

### 10. Advanced Topics
- Advanced Pandas
- SQL fundamentals
- Working with APIs
- Power BI and dashboards
- Introduction to machine learning

## Tools & Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- SciPy
- SQL
- Power BI

## Learning Goals
- Develop strong data analysis skills.
- Learn to clean and manipulate data.
- Understand and interpret datasets.
- Create meaningful visualizations.
- Apply knowledge to real-world projects.
